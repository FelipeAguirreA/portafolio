# 🚀 Portafolio Felipe Aguirre

Portafolio profesional interactivo con animaciones GSAP estilo música electrónica.

## 📁 Estructura del Proyecto

```
portafolio/
├── index.html          # Página principal
├── css/
│   └── style.css       # Estilos
├── js/
│   └── script.js       # Animaciones
├── assets/images/      # Imágenes
├── README.md           # Documentación
└── .git/               # Control de versiones
```

## ✨ Características

- ✅ Animaciones energéticas tipo música electrónica
- ✅ Efectos hover sincronizados
- ✅ Scroll triggers y parallax
- ✅ Responsive design
- ✅ Formulario de contacto
- ✅ Navegación suave

## 🛠️ Tecnologías

- **HTML5** - Estructura semántica
- **CSS3** - Estilos y responsividad
- **JavaScript ES6+** - Interactividad
- **GSAP v3.12.2** - Animaciones
- **ScrollTrigger** - Scroll-based animations
- **Font Awesome 6.4.0** - Iconos

## 🚀 Cómo Usar

```bash
# Opción 1: Abre directamente
# Abre index.html en tu navegador

# Opción 2: Usa un servidor local
python -m http.server 8000
# Accede a http://localhost:8000
```
